# ChatTrace 新手图文指南

> 面向第一次使用 ChatTrace 的人。照着走一遍，大约 5 分钟即可完成首轮解密与导出。
> 全程在本机完成，不需要网络，也不需要把任何数据交给别人。

---

## 一、开始前，先确认三件事

| 检查项 | 说明 |
| --- | --- |
| **系统** | Windows 10 / 11（x64） |
| **微信版本** | 微信 4.x，**4.1.11 或更高**（更低版本请用旧工具，本工具面向 4.1.11+ 的内存形态变更） |
| **账号数据** | 本机存在 `xwechat_files` 目录（一般在 `文档\xwechat_files`，也可能被你迁移到其他盘） |

另外记住一条经验：**解压路径不要含中文**（例如解压到 `D:\ChatTrace` 而不是 `D:\我的工具\微信导出`），
可以避免极少见的编码问题。

## 二、五步流程

### 第 1 步 · 选择账号

![第 1 步：选择账号](images/step1-account.png)

1. 双击 `ChatTrace.exe`（免安装）。浏览器会自动打开 `http://127.0.0.1:8714`。
2. 在输入框填入 `xwechat_files` 根目录（或点「📁 浏览选择…」），点「扫描该目录」。
3. 列表中会列出本机检测到的账号目录，点右侧「选择」。

> 如果列表为空：确认路径是否真的是 `xwechat_files`（它下面应该直接是 `wxid_xxx_xxxx` 这样的目录）。
> 也可以在输入框里直接粘贴某个账号目录的完整路径。

### 第 2 步 · 获取密钥

![第 2 步：密钥](images/step2-key.png)

微信数据库用 32 字节主密钥加密，这个密钥只在**登录过程中**短暂出现在内存里。
最稳的获取方式是让微信"干净地登录一次"：

1. **先正常打开微信，确认能自动登录**（不需要扫码/手机确认的那种状态）；
2. **从系统托盘右键退出微信**（不是点窗口右上角的 ✕ —— 那样只是最小化到托盘）；
3. 回到 ChatTrace 页面，点「重新获取密钥」。

ChatTrace 会自动拉起微信、在密钥进入加密引擎前截获它，并当场用数据库做一次校验：

- 校验通过 → 显示 `密钥已就绪（fp=xxxxxxxx…）`，只显示指纹，不显示密钥本身；
- 校验不通过 → 会自动丢弃重试；多次失败时会提示你改用手动填钥。

> **手动路径**：如果你从其他渠道已经拿到 64 位十六进制密钥，展开「已有关键信息（高级）」粘贴，
> 点「校验并保存」——ChatTrace 会先校验再保存，避免存下无效密钥。

密钥默认 **24 小时** 有效；微信重启、换号或升级后需要重新获取（界面会提示）。

### 第 3 步 · 解密数据

![第 3 步：解密数据](images/step3-decrypt.png)

点「解密 / 增量刷新」即可。页面会逐个库显示进度与结果：

- `contact` / `session` / `message_*`（分片）/ `media_*` / `favorite` 等，本机实测为 **25 个库**；
- 每个库都用它自己的 salt 独立派生密钥，解密后做一次 SQLite 冒烟校验，确保产物真的能打开；
- **重复运行只补新数据**：时间戳与大小没变的库会直接跳过（显示 `已就绪`），所以日常使用只需偶尔点一次。

> 解密产物是**明文副本**，写在 `%LOCALAPPDATA%\ChatTrace\accounts\<账号>\decrypted\`。
> **原始数据始终只读**，不会被修改。想彻底清理时，删掉 `%LOCALAPPDATA%\ChatTrace` 即可。

### 第 4 步 · 浏览聊天

![第 4 步：浏览聊天](images/step4-browse.png)

左侧是会话列表（支持按名称、备注、摘要搜索），右侧是消息时间线：

- **图片**：能离线解密的会**直接显示**，点开可看大图；
- **语音**：显示为可点击的下载链接（导出为 `.silk` 原始格式，见下方 FAQ）；
- **视频**：有原文件的显示为可下载链接；只剩缩略图的会注明「原视频已被微信清理」；
- **无法直接显示的少数内容**：约 14% 的**原图**是微信私有的 WxAM 压缩格式，ChatTrace 会自动改用
  该图的缩略图呈现（照样看得见），并在卡片上注明原图格式，**不会伪造占位图**。

### 第 5 步 · 导出

![第 5 步：导出](images/step5-export.png)

1. 在「浏览聊天」里选中一个会话，点右上角「导出…」（会自动跳到第 5 步）；
2. 选择格式，勾选「包含媒体」；
3. 点「开始导出」。

| 格式 | 用途 | 含媒体时的表现 |
| --- | --- | --- |
| `.html` | 网页气泡视图，最适合长期阅读/存档 | 附带同目录 `<会话名>_assets\` 文件夹：图片、**可播放的语音 WAV**、视频都在里面，页面内直接显示/播放 |
| `.json` | 结构化数据，适合脚本处理与迁移 | 每条媒体消息附加 `media` 状态字段（类型/可用性/说明） |
| `.txt` | 纯文本，最轻量 | 每条媒体消息附加状态标注 |

导出结果默认在 `%LOCALAPPDATA%\ChatTrace\accounts\<账号>\exports\`，页面提供「打开所在文件夹」。

> **HTML + _assets 目录要一起保存**：单独复制 `.html` 文件，图片就会显示不出来。

## 三、进阶：命令行（与界面能力等价）

```powershell
$acct = "D:\...\xwechat_files\wxid_xxx"

chattrace doctor                       # 环境自检：frida / 微信 / 锚点 / 密钥目录
chattrace keyagent run --store --account-dir $acct    # 自动获取并保存密钥
chattrace data decrypt --account-dir $acct            # 增量解密
chattrace chat list --account-dir $acct               # 会话列表
chattrace chat read --account-dir $acct wxid_好友 --limit 30
chattrace export --account-dir $acct --user wxid_好友 --format html --media
```

## 四、常见问题（FAQ）

### 扫描不到账号目录
确认选的是 `xwechat_files` 根目录（其下直接是 `wxid_...` 账号目录），而不是 `db_storage` 或某个库文件。
微信 4.x 也可能把数据放在非默认盘（迁移过的用户），用「浏览选择…」手动定位即可。

### 密钥总是获取不到
按顺序排查：

1. 微信是否处于**能自动登录**的状态？不能自动登录时，先手动登录一次再重试；
2. 退出微信时是否用了**托盘退出**（✕ 只是最小化到托盘，密钥可能已被清理）；
3. 微信是否有新版本？版本未登记时 ChatTrace 会尝试自动定位锚点，失败会给出可上报的诊断信息；
4. 微信进程杀不死 / 拉起后一直不登录 → 见下方错误码对照。

### 界面提示「密钥已过期，建议重新获取」
密钥默认 24 小时 TTL。这**不影响阅读已解密的内容**，只是提示你：想解密新数据前，最好重新获取一次
（微信重启、换号、升级后密钥会变）。

### 图片为什么有的显示原图、有的是缩略图
- **原图**：绝大部分图片（旧格式与 2025 年后的新版 V2 容器）都能离线解出原图，直接显示并标注尺寸与大小，
  点击可看大图。V2 的密钥由本机的 `kvcomm` 密钥缓存与账号 wxid 推导，**不需要微信在运行**。
- **缩略图**：约 14% 的**原图**是微信私有的 WxAM 压缩格式（需要专用 HEVC 解码器）。这种情况下
  ChatTrace 会自动改用同一张图的缩略图显示——你照样看得见这张图，只是分辨率略低，卡片上会写明原因。

导出 HTML 时同样如此：能出原图就出原图，只能出缩略图就出缩略图并注明。

### 语音为什么可以直接播放？能导出吗
能。ChatTrace 会把微信的 SILK 语音**在本地解码成 WAV**（不联网、不上传），所以聊天页里
语音就是一个正常的播放条，点一下即可听，不需要额外软件。
导出 HTML 时会一起写入 `_assets` 目录，页面里同样是可播放的播放条。

如果某条语音显示为「语音 6″（本机缓存已过期）」，说明微信已经清理了那条语音的本地缓存——
时长仍能如实显示，但本体已不在本机，任何人都无法恢复。

### 图片为什么有的直接显示、有的是一张说明卡片
- **直接显示**：绝大多数图片都会直接显示（旧格式与新版 V2 容器都能离线解码），并标注尺寸与大小，点击看大图；
- **说明卡片**：仅当这张图的**原图与缩略图都无法解码**（例如文件已被微信清理、或只剩 WxAM 原图且没有缩略图）时，
  ChatTrace 会显示该图的**尺寸、大小与原因**，而不是伪造一张假图或留一个空洞。

### 视频只有一张缩略图
微信会定期清理本地视频本体。原文件已被清理时，ChatTrace 会显示仍存在的缩略图并注明原因。

### 消息里的"文件""链接""引用"是什么样子
它们都会被渲染成卡片：文件显示文件名与类型，链接显示标题与地址，引用显示被引用的原文与被引用人，
位置显示地名与坐标，语音通话显示时长，名片显示昵称与微信号——即"能读到的信息一个都不丢"。

### 解密时某个库失败
最常见原因是**微信正在运行并占用该库**。关闭微信（托盘退出）后重试即可。
解密是增量的，已成功的库不会重做。

### 杀毒软件报警 / 提示注入行为
ChatTrace 用 Frida 在**自己拉起的微信进程**里读取密钥，杀软可能因此告警（属于注入类工具的常见误报）。
如果你介意，也可以用手动填钥路径（第 2 步的高级选项）完全避开注入。

### 会不会把我的聊天数据传出去？
不会。ChatTrace 不包含任何联网上传代码：密钥、明文副本、导出结果都在本机
`%LOCALAPPDATA%\ChatTrace\`；界面只监听 `127.0.0.1`（仅本机可访问）。

## 五、错误码对照表

界面在失败时会给出具体错误码与引导：

| 码 | 含义 | 建议动作 |
| --- | --- | --- |
| `ERR_NO_WEIXIN` | 未检测到微信 / `Weixin.dll` | 确认微信已安装；路径异常时手动指定 `Weixin.exe` |
| `ERR_LOGIN_TIMEOUT` | 拉起微信后未完成自动登录 | 先手动正常登录一次 → 托盘退出 → 重试 |
| `ERR_UNSUPPORTED_VERSION` | 版本未登记且自动定位失败 | 升级 ChatTrace；附上微信版本与诊断信息提 Issue |
| `ERR_NO_VALID_KEY` | 候选密钥未通过校验（重试后） | 改用手动填钥；确认微信登录态正常 |
| `ERR_WECHAT_CRASH` | 抓取期间微信崩溃 | 重启微信后重试；若反复出现请提 Issue（附版本） |
| `ERR_FRIDA` | Frida 缺失或不可用 | 安装包自带运行时；源码安装请确认 `pip install -e .` 已完成 |
| `ERR_CLEANUP` | 清理自建微信实例失败 | 按提示手动结束残留进程；ChatTrace 不会杀你的手动实例 |
| `ERR_ACCOUNT` | 账号目录/库文件找不到或存在歧义 | 重新在第 1 步选择正确的账号目录 |
| `ERR_KEY_STORE` | 密钥文件读写失败 | 检查 `%LOCALAPPDATA%\ChatTrace\keys` 权限；或删除后重新获取 |

## 六、使用完毕后的清理

- **只清理导出结果**：删除 `%LOCALAPPDATA%\ChatTrace\accounts\<账号>\exports\`；
- **清理明文副本与缓存**：删除 `%LOCALAPPDATA%\ChatTrace\accounts\<账号>\decrypted\` 与 `media_cache\`；
- **彻底清理（含密钥）**：删除整个 `%LOCALAPPDATA%\ChatTrace`。删除后下次使用需重新获取密钥。

原始微信数据（`xwechat_files`）不会被 ChatTrace 修改，删除上述目录即可回到使用前的状态。

## 七、边界与责任

ChatTrace 只应用于**导出你本人账号、本机**的聊天数据。它是非官方工具，与腾讯/微信无任何关联；
请勿用于他人账号或未授权数据。逆向研究可能触及平台条款与法律风险（社区已有因平台函件删库的先例），
请自行评估后再使用。详见 [../NOTICE.md](../NOTICE.md)。
